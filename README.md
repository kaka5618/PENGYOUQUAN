# PENGYOUQUAN

朋友圈图文助手小程序。

立项日期：2026-11-03。当前阶段：需求整理与产品方案，尚未开始小程序开发。

## 产品目标

帮助用户把自己的照片、经历或想表达的内容整理成有审美、容易发布的朋友圈，提供图片排列、文案编辑和发布顺序指导。

## 本次立项方向

- 提供可选择、可替换个人素材的朋友圈模板。
- 规划每条朋友圈的图片角色与排列顺序。
- 支持文案编辑，并保留用户提供的真实事实。
- 提供明确的保存、选图与发布步骤。
- 预览需考虑微信展示差异，避免仅依赖旧版主页的字母排版。

以上为本次讨论方向；首版功能边界和技术方案待下一阶段确定。
